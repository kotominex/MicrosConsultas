Usuario

1. Completa formulario de login
2. POST /api/auth/login {email, password}
3. Enruta (Path=/api/auth/**)
4. SELECT * FROM users WHERE email = ?
5. user{password_hash, role}
6. passwordEncoder.matches(password, hash)
7. jwtProvider.generateToken(id, email, role)

10. localStorage.setItem('auth_token', token)
11. Redirige a /projects

Flujo 3: Scheduler automático — marcar tareas OVERDUE

Flujo autónomo, sin intervención del usuario: se ejecuta dentro de core-service según el cron configurado (scheduler.overdue.cron, cada hora por defecto).

OverdueTaskScheduler
(@Scheduled, core-service)
core_db
1. Cron dispara (scheduler.overdue.cron, cada hora por defecto)
2. UPDATE tasks SET status='OVERDUE', updated_at=now()
   WHERE status NOT IN (DONE,OVERDUE) AND due_date < CURRENT_DATE
3. N filas actualizadas
4. log.info("Tareas marcadas como OVERDUE: {}", N)
Fuente: OverdueTaskScheduler, TaskRepository.markOverdue() (core-service) · regla de negocio de ARQUITECTURA.md sección 2.6.
