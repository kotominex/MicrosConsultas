Modelo de Base de Datos

MicrosConsultas — Sistema de Gestión de Proyectos y Tareas · Generado a partir de las migraciones Flyway

El sistema usa una instancia de PostgreSQL con dos bases de datos físicamente separadas, una por cada microservicio de negocio (patrón database-per-service): auth_db (propiedad de auth-service) y core_db (propiedad de core-service). No existe llave foránea física entre ambas bases — core_db.projects.owner_id referencia lógicamente a auth_db.users.id únicamente a través del claim sub del JWT emitido por auth-service.
